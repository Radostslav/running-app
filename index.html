      Jak získat token
      1. Otevři github.com/settings/personal-access-tokens/new
      2. Token name: TRImates, Expiration: 1 rok
      3. Repository access: Only select repositories → running-app
      4. Permissions → Repository permissions → Contents: Read and write
      5. Generate token, zkopíruj ho a vlož sem
